# 🛍️ Customer Shopping Behavior Analysis


## 📌 Overview
This project presents an end-to-end data analytics workflow focused on analyzing customer shopping behavior.

The objective was to extract meaningful business insights by:

- Cleaning and preparing raw data
- Performing Exploratory Data Analysis (EDA)
- Writing SQL queries in PostgreSQL
- Building an interactive Power BI dashboard
- Creating a business report and presentation

---

## Business Problem

“How can the company leverage consumer shopping data to identify trends, improve 
customer engagement, and optimize marketing and product strategies?”   

---

## 📊 Dataset

The dataset contains customer shopping behavior information, including:

- Customer demographics
- Purchase history
- Product categories
- Spending patterns
- Transaction details

The data was initially loaded and explored using Python, then stored and queried using PostgreSQL.

---

## 🔄 Project Workflow / Steps

1️. Data Loading (Python)

- Imported dataset using Pandas
- Checked structure, data types, and summary statistics  
  
2. Data Cleaning

- Handled missing values
- Removed duplicates
- Corrected inconsistent data types
- Standardized categorical values

3️. Exploratory Data Analysis (EDA)

- Analyzed customer demographics
- Identified top product categories
- Examined spending patterns
- Visualized trends and distributions

4️. SQL Analysis (PostgreSQL)

- Imported cleaned dataset into PostgreSQL
- Wrote SQL queries for:
- Total sales analysis
- Category-wise revenue
- Customer segmentation
- Monthly/Yearly trends
- Used GROUP BY, JOIN, HAVING, subqueries, and aggregations

5️. Power BI Dashboard

- Connected Power BI to PostgreSQL
- Created interactive visuals and KPIs
- Designed filters, slicers, and drill-down analysis  
  
6. Reporting & Presentation

- Generated a structured business report
- Created a professional presentation using Gamma
- Highlighted key findings and recommendations
